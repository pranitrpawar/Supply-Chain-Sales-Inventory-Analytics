
# 📊 Supply Chain Sales & Inventory Analytics 

## 📌 Project Overview

An interactive **Power BI dashboard** developed to analyze end-to-end supply chain business performance including **Sales, Customers, Products, Suppliers, Purchase Orders, Inventory, Warehouses, Shipments and Returns**.

## 🎯 Objectives

- Analyze sales and profit performance
- Track customers and top-selling products
- Monitor purchase orders and suppliers
- Analyze warehouse inventory and stock levels
- Track shipment status and logistics cost
- Analyze return reasons and refunds

The dashboard helps identify:

- Top customers and products
